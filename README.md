# 와이펫 웹

안드로이드 `ypet_feeder` 앱의 화면을 바탕으로 만든 HTML·CSS·JavaScript 웹앱입니다. 별도 빌드나 패키지 설치가 필요하지 않습니다.

## 사용

- `index.html`을 열거나 정적 웹 서버에서 이 폴더를 제공하세요.
- 홈, 리포트, 설정, 반려동물 프로필과 체중 기록을 지원합니다.
- 홈의 **시연 시작**을 누르면 가상 저울이 8초마다 변합니다. 시연 기록은 실제 기기 기록과 구분해 표시합니다.
- 기록은 브라우저의 localStorage에 저장합니다. 설정에서 JSON 백업/복원, 리포트에서 CSV 내보내기를 지원합니다.
- 사료 급여 기준량은 사용자가 직접 설정합니다. 원래 앱의 데모 급여량 계산을 실제 영양 권장 알고리즘으로 제시하지 않습니다.

## 실제 저울 연결

설정에서 저울별 **무게 데이터 전체 주소**를 입력합니다. 원래 앱에서 발견한 경로는 `/api/weight`이지만, 실제 기기 계약은 확인하지 못했으므로 사용 중인 기기에 맞는 전체 주소를 넣어야 합니다.

다음 응답을 지원합니다. 단위는 g입니다.

```json
{"grams": 120}
```

`weightGrams`, `weight_grams`, `weight_g`, `weight`, `value` 키 또는 숫자만 반환하는 응답도 지원합니다. 첫 측정은 기준값이며 이후 2 g 이상 감소한 양을 섭취로, 증가한 양을 채움으로 기록합니다. 물은 1 g = 1 ml로 표시합니다. 기기를 연결할 때 이전 시연 무게와 실제 무게의 차이를 섭취로 세지 않습니다.

브라우저를 열어둔 동안 1분마다 읽습니다. 브라우저가 닫혀 있을 때의 수집·백그라운드 알림·다른 기기로의 동기화는 제공하지 않습니다. 서버 없이 GitHub Pages에서 운영하는 버전의 제한입니다.

공개 HTTPS 웹사이트에서 연결하려면 저울 API도 HTTPS와 적절한 CORS 응답을 제공해야 합니다. HTTP만 제공하는 로컬 저울은 별도 HTTPS 중계 서버 등이 필요할 수 있습니다. 실제 하드웨어로 통합 검증하지 않았습니다.

## GitHub Pages

1. `ypet-feeder-web` 저장소 루트에 이 폴더의 파일을 올립니다.
2. GitHub 저장소 **Settings → Pages → Deploy from a branch**에서 `main`과 `/(root)`를 선택합니다.
3. 배포 주소: `https://kyokushin83.github.io/ypet-feeder-web/`

앱을 한 번 온라인에서 연 뒤에는 저장된 화면을 오프라인으로 다시 열 수 있습니다. 설치 지원 여부는 브라우저와 운영체제에 따라 다릅니다. 개인 기록은 저장소나 GitHub로 전송하지 않습니다. 사용자가 직접 연결한 저울 주소로는 무게 읽기 요청을 보냅니다.
